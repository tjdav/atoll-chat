This report evaluates the implementation scale and architectural requirements for Key Transparency in Server Specification v2.0 relative to RFC 6962 ("Certificate Transparency"). It resolves the specification ambiguity between a full RFC 6962 web-PKI transparency log and a simplified append-only log by recommending **Interpretation B (RFC 6962-lite)**—an RFC 6962 binary Merkle tree with Ed25519 Signed Tree Heads and inclusion proof endpoints for client identity key verification, while omitting web-PKI consistency proofs and multi-log gossip protocols.
